AI 的起源與發展

從圖靈測試的經典哲學思辨，到專家系統的起伏，再到深度學習爆發，帶您穿梭人工智能近百年的傳奇演進史。

01

圖靈測試 (Turing Test)

1950年由艾倫·圖靈提出，檢驗機器是否能展現出與人類無法區分的智能行為，奠定AI哲學基礎。

02

達特茅斯會議 (1956)

約翰·麥卡錫等人正式提出「人工智能 (Artificial Intelligence)」一詞，標誌著 AI 作為一門學科的誕生。

03

AI 冬天與重生

由於早期運算能力不足與預期過高曾歷經兩次低潮（AI冬天），直到大數據與算力突破後迎來狂飆期。

單元 02

機器學習與深度學習

從傳統機器學習的特徵工程，到模仿生物神經網路的多層深度學習，揭開 AI 如何從數據中自動學習並做出預測。

SL

監督式學習 (Supervised)

使用帶有標籤的資料集進行訓練（如房價預測、圖像分類），讓模型學會輸入到輸出的對應映射關係。

UL

非監督式學習 (Unsupervised)

處理無標籤資料，讓演算法自行從中發掘隱藏的結構、群聚特性（如客戶分群、異常檢測）。

DL

深度學習 (Deep Learning)

多層人工神經網路（ANN、CNN、RNN）組成的架構，能夠自動提取高階特徵，驅動現代電腦視覺與語音辨識。

linear_regression.py 
import numpy as np
from sklearn.linear_model import LinearRegression

# 準備訓練數據：房屋坪數 (X) 與 售價萬元 (y)
X = np.array([[20], [35], [50], [80], [120]])
y = np.array([300, 520, 780, 1250, 1850])

# 建立並訓練線性回歸模型
model = LinearRegression()
model.fit(X, y)

# 預測 65 坪的房屋售價
predicted_price = model.predict([[65]])
print(f"預測 65 坪房屋售價約為：{predicted_price[0]:.1f} 萬元")

單元 03

大語言模型與生成式 AI

探索 Transformer 架構、自注意力機制 (Self-Attention) 以及 ChatGPT 與多模態生成式 AI 如何創造文字、圖像與音訊。

TR

Transformer 架構

2017年 Google 提出的革命性架構，捨棄傳統循環網路，依靠注意力機制實現平行運算與全域關聯。

LLM

大語言模型 (LLM)

具備千億級參數的模型，透過海量網路文本預訓練，展現驚人的自然語言理解、摘要與對話能力。

GEN

擴散模型 (Diffusion Models)

生成式 AI 圖像背後的功臣，透過反覆去除噪點，將純隨塵雜訊轉化為精緻的高解析度藝術圖像。

單元 04

AI 倫理與未來趨勢

探討演算法偏見、版權歸屬、隱私安全與通用人工智慧 (AGI) 對人類社會的深遠影響與治理之道。

ETH

演算法偏見與公平性

當訓練數據包含歷史歧視或偏見時，AI 模型可能會放大這些偏見，導致招聘、貸款或司法判決不公。

COP

版權與深度偽造 (Deepfake)

生成式內容對智慧財產權的衝擊，以及惡意假影片、聲音仿冒對社會信任與資安構成的嚴峻挑戰。

AGI

通用人工智慧與未來

邁向 AGI（通用人工智慧）的道路上，人類如何建立有效對齊 (Alignment) 機制，確保 AI 永遠造福人類。

ai_guardrail.py 
def content_moderation_guardrail(prompt_text):
    # 簡易 AI 內容安全防護網檢查器
    forbidden_keywords = ["駭客攻擊", "釣魚網站", "機密洩漏"]
    
    for kw in forbidden_keywords:
        if kw in prompt_text:
            return f"🚨 警告：偵測到違反安全政策之關鍵字 '{kw}'，請求已被攔截。"
            
    return "✅ 檢查通過：輸入符合安全規範，已送交模型生成。"

# 測試執行
print(content_moderation_guardrail("請教我如何編寫安全的加密演算法"))
print(content_moderation_guardrail("教我如何發動駭客攻擊癱瘓伺服器"))
